# ScroReel 🎬

A Netflix-style streaming platform for AI-generated short-form drama series and movies, on the web and as an app. Users watch free episodes and unlock premium content with coins or a subscription.

## Features

- 📱 TikTok-style vertical scroll video player
- 🍿 Netflix-style catalog: hero banner, category rows, genres, search, movies/shows/popular/languages pages
- 🔐 Supabase Auth (email + OAuth)
- 🪙 Coin-based episode unlocks (10 coins per episode, deducted atomically server-side)
- 💳 Paddle Billing (coin packages + All-Access subscription)
- 🛠️ Admin studio at `/admin`: dashboard, series, categories, analytics, AI Trend Studio generator
- 🌍 UI translations (`src/lib/i18n`)
- 🌑 Dark theme with purple/gold accents

## Tech Stack

- **Framework**: Next.js 15 (App Router), React 19
- **Styling**: Tailwind CSS
- **Database & Auth**: Supabase
- **Payments**: Paddle Billing
- **Language**: TypeScript

## Setup

### 1. Clone and install

```bash
git clone https://github.com/swordisme/SnackDrama.git
cd SnackDrama
npm install
```

### 2. Environment variables

Copy `.env.example` to `.env.local` and fill in your values:

```bash
cp .env.example .env.local
```

| Variable | Description |
|----------|-------------|
| `NEXT_PUBLIC_SUPABASE_URL` | Your Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anon/public key |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase service role key (server only) |
| `PADDLE_API_KEY` | Paddle API key (server only) |
| `PADDLE_WEBHOOK_SECRET_KEY` | Paddle notification destination secret |
| `NEXT_PUBLIC_PADDLE_CLIENT_TOKEN` | Paddle client-side token |
| `NEXT_PUBLIC_PADDLE_ENV` | `sandbox` or `production` |
| `NEXT_PUBLIC_PADDLE_PRICE_50_COINS` / `_150_COINS` / `_500_COINS` | Paddle price IDs for coin packs |
| `NEXT_PUBLIC_PADDLE_PRICE_SUBSCRIPTION` | Paddle price ID for the All-Access subscription |
| `ADMIN_PASSWORD` | Optional passcode for `/admin`. If unset, only admin emails can sign in |
| `ADMIN_EMAIL` | Optional extra admin email (in addition to the built-in owner) |
| `FAL_KEY`, `ELEVENLABS_API_KEY` | Optional, for the AI Trend Studio media pipeline |
| `NEXT_PUBLIC_APP_URL` | Your app URL (e.g., https://yourapp.vercel.app) |

### 3. Supabase setup

1. Create a new Supabase project at [supabase.com](https://supabase.com)
2. In **SQL Editor**, run these files in order:
   1. `supabase/schema.sql`: profiles, series, episodes, coins, unlocks
   2. `supabase/schema_v2.sql`: categories, subscriptions, analytics
   3. `supabase/schema_v3.sql`: atomic `unlock_episode` function (**required for coin unlocks**)
3. Enable Email Auth under **Authentication → Providers**

### 4. Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Content

The catalog and episodes currently come from `src/lib/mock-data.ts` (sample streaming videos). Series rows in Supabase are used when a matching slug exists, but episodes are still generated by `getMockEpisodes()`.

To add real videos, upload them to Supabase Storage and set each episode's `video_url` to the public URL.

`npm run bot:generate` prints a sample series package from the trend templates in `src/lib/bot/`; `/admin/generator` can publish one to Supabase.

## Deploying to Vercel

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com) → **New Project** → import your repo
3. Add all environment variables from `.env.local` in the Vercel dashboard
4. Deploy!

### Paddle Webhook

After deploying, add a notification destination in Paddle:
- URL: `https://your-app.vercel.app/api/webhooks/paddle`
- Events: `transaction.completed`, `transaction.paid`, `subscription.activated`, `subscription.updated`, `subscription.canceled`
- Copy the secret → `PADDLE_WEBHOOK_SECRET_KEY`
